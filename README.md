# Мозаика культур

Статический образовательный сайт о коренных народах Хабаровского края.

## Текущий режим публикации

Сайт подготовлен для бесплатной публикации на Netlify через GitHub:

- регистрация скрыта;
- форма обратной связи работает через Netlify Forms;
- Supabase Auth и таблица обратной связи сохранены в коде и могут быть включены позже переменными окружения.

## Локальный запуск

```bash
npm start
```

Сайт откроется на `http://127.0.0.1:4173`.

## Сборка

```bash
npm run build
```

Готовые файлы появятся в папке `dist`. Эту папку не нужно загружать в GitHub: Netlify соберет ее сам.

## Netlify

При подключении репозитория укажите:

```text
Build command: npm run build
Publish directory: dist
```

Переменные окружения сейчас не нужны. Если позже понадобится регистрация через Supabase, добавьте:

```text
SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
```

## Supabase на будущее

SQL для таблицы обратной связи лежит в `supabase-setup.sql`. Подробная инструкция находится в `DEPLOY.md`.
