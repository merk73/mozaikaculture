# Мозаика культур

Статический образовательный сайт о коренных народах Дальнего Востока.

## Текущий режим публикации

Сайт подготовлен для бесплатной публикации через GitHub Pages и может также собираться на Netlify/Vercel:

- регистрация работает через Supabase Auth при наличии переменных окружения;
- форма обратной связи отправляет сообщения в таблицу Supabase;
- GitHub Actions собирает `dist` и публикует сайт на GitHub Pages.

## Локальный запуск

```bash
npm start
```

Сайт откроется на `http://127.0.0.1:4173`.

## Сборка

```bash
npm ci
npm run build
```

Готовые файлы появятся в папке `dist`. Эту папку не нужно загружать в GitHub: GitHub Actions соберет ее сам.

Сборка сжимает JavaScript и объединяет CSS, сохраняя порядок стилей. Имена опубликованных файлов содержат хеш содержимого: общие стили повторно используются между страницами, а изменённые файлы получают новый адрес. Чтобы проверить итоговую сборку локально, запустите `npm start` и откройте `http://127.0.0.1:4173/dist/`.

Фирменный шрифт загружается в WOFF2 (12 КБ вместо 59 КБ). Исходный OTF и лицензия сохранены. Для пересоздания WOFF2 используйте `scripts/prepare-web-font.py` с установленными `fonttools` и `brotli`.

Библиотека личного кабинета загружается независимо от меню; на мобильной главной — после завершения экрана загрузки. Без настройки Supabase библиотека не скачивается. Квиз позволяет сразу выбрать гостевой режим во время подключения кабинета.

## Изображения главной на мобильных

На экранах до 760 px обложка и атлас используют WebP из `assets/home-mobile-v3`: портреты атласа имеют варианты 256/384/512 px, фоны карточек — 256 px. Остальные мобильные фотографии используют адаптивные варианты. Оригиналы доступны в ссылках для просмотра целиком. Фоны нижних блоков и обложки видео загружаются по мере необходимости.

После замены исходных изображений пересоздайте мобильные версии (Python с Pillow):

```bash
python scripts/optimize-home-images.py
```

Главная загружает компактный `home-peoples.js` и выводит атлас до библиотеки авторизации. `npm run build` пересоздаёт эти данные из `content.js` и `far-east-peoples.js`; для локального просмотра после правок текстов выполните `node scripts/generate-home-data.mjs`.

На мобильной главной экран с логотипом остаётся до загрузки и декодирования всех портретов атласа. Эти изображения загружаются сразу; остальные блоки сохраняют отложенную загрузку. Ошибки отдельных изображений или скриптов атласа не блокируют доступ к странице.

При изменении параметров сжатия используйте новую версию каталога изображений и обновите ссылки, чтобы браузер загружал новые файлы вместо закешированных.

## Иконка веб-приложения

Иконки для добавления сайта на главный экран находятся в `assets/app-icons-v1`, настройки приложения — в `site.webmanifest`. На iPhone используется PNG 180×180, на Android — 192×192 и 512×512 с отдельной иконкой для системной обрезки. Фон взят из кнопки квиза, логотип — из `assets/logo-mozaika.svg`.

После изменения оформления пересоздайте иконки командой `node scripts/prepare-app-icons.mjs` (нужен пакет `sharp`). Для обновления ссылок на всех страницах выполните `node scripts/add-app-icon-links.mjs`. Готовые PNG входят в обычную сборку; `sharp` не требуется для публикации.

## Netlify

При подключении репозитория укажите:

```text
Build command: npm run build
Publish directory: dist
```

Для регистрации и обратной связи добавьте переменные окружения:

```text
SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
```
